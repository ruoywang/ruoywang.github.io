Decrypting without a browser 
Format: AES-256-GCM. key = PBKDF2-HMAC-SHA256(password_utf8, base64decode(salt), 600000 iterations, 32 bytes).
plaintext = AESGCM(key).decrypt(base64decode(iv), base64decode(ct), None)   (ct includes the 16-byte tag)
salt, iv, ct and iter are in the JSON of the LAST <script type="application/json" id="payload"> element of the page.

Python:
  import base64, hashlib, json
  from cryptography.hazmat.primitives.ciphers.aead import AESGCM
  d = json.loads(page_html.rsplit('id="payload">', 1)[1].split('</script>', 1)[0])
  b = base64.b64decode
  key = hashlib.pbkdf2_hmac("sha256", PASSWORD.encode(), b(d["salt"]), d["iter"], 32)
  print(AESGCM(key).decrypt(b(d["iv"]), b(d["ct"]), None).decode())

A link of the form  page.html#pw=PASSWORD  opens the page directly in a browser.
